# Anápolis Auto Center: proposta de site

Proposta de site premium para a Anápolis Auto Center, feita pela [Divinus](https://divinustecnologia.com.br). Projeto de front-end em HTML, CSS e JavaScript, sem dependências.

## Conteúdo

- `index.html`: primeira versão da proposta.
- `v2.html`: segunda versão.
- `painel/index.html`: exemplo de painel.

## Como ver

Abra o `index.html` no navegador.

## Observação

A marca, os textos e as imagens pertencem à Anápolis Auto Center e aparecem aqui apenas como exemplo de trabalho.
